# جمعية الشهيد للأيكيدو - سلا | Association Chahid AIKIDO - Sale

Official website for the **Association Chahid Martial Arts (Aikido)** based in Salé, Morocco.
الموقع الرسمي لـ **جمعية الشهيد للفنون القتالية (الأيكيدو)** مقرها سلا، المغرب.

## 🚀 المميزات | Features

- **Design**: Modern, premium, and responsive dark-themed design.
- **RTL Support**: Full support for Arabic language (Right-to-Left).
- **Sections**: Home, About, Instructors, and Achievements pages.
- **Interactivity**: Smooth scroll animations and dynamic navbar (Scroll Spy).
- **Direct Contact**: Integrated WhatsApp registration link.

## 🛠 التقنيات المستخدمة | Tech Stack

- HTML5
- CSS3 (Vanilla CSS with CSS Variables)
- Vanilla JavaScript (Intersection Observer API)
- Google Fonts (Cairo)

## 📂 Structure

- `index.html`: Main landing page.
- `pages/achievements.html`: Highlights and milestones.
- `static/css/style.css`: All styling and animations.
- `static/js/script.js`: Interactive components and scroll logic.
- `static/images/`: Assets and photographs.
